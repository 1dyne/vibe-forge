01   시스템 구조

블록 다이어그램 — 왼발(기존) vs 오른발(해커톤)

양쪽 동일한 것 — FSR402 4채널 / 10kΩ 분압 회로 / 3.3V 기준 전압 / 깔창 압력점 배치 / 케이블 색상 표준 / 데이터 포맷 fsr1~4,roll,pitch,yaw 10Hz / BLE Nordic UART Service / PWA 대시보드 (무수정)
02   회로도

Schematic — 오른발 해커톤 유닛

분압 회로 방향 — 왼발과 동일
3.3V → R(10kΩ) → [측정점] → FSR → GND
압력 증가 → FSR 저항 감소 → 측정점 전압 하강 → ADC 값 감소. 펌웨어에서 반전 필요.

주의: ADS1015는 단일 입력 시 11비트고, PGA 설정에 따라 풀스케일이 달라져. 1023 - read() 상수를 그대로 쓰면 안 되고, mV 단위로 변환한 뒤 반전하는 게 안전해. PGA ±4.096V 기준 3.3V ≈ 1650카운트.

나사단자 배선표

단자연결케이블 색상압력점
A0R1·FSR#1 측정점빨강엄지 끝
A1R2·FSR#2 측정점노랑엄지 뿌리
A2R3·FSR#3 측정점초록새끼 옆
A3R4·FSR#4 측정점파랑뒷꿈치
3V3 핀R1~R4 상단 (4갈래)—분압 상단
GND 핀FSR#1~4 하단 (4갈래)검정공통 접지
A3 트림팟 격리 필요
ADS1015 보드에는 A3 채널에 10kΩ 트림팟이 기본 연결돼 있어. FSR#4를 A3에 물리려면 격리 점퍼를 끊어야 해. 보드 수령 후 가장 먼저 확인할 것.
03   부품 명세서

Bill of Materials — 해커톤 오른발 유닛

구매 필요 보유 · 재사용 현장 대여 선택
#분류부품명규격수량상태비고
01전자 SparkFun Qwiic 12Bit ADC ADS1015, 4채널, DEV-15334 2 구매 필요 오늘 주문 필수. 여유분 1개 포함. 나사단자 있는 SparkFun판으로. Adafruit STEMMA QT판은 나사단자 없음
02전자 FSR402 압력 센서 0.5인치 원형 4 구매 필요 오른발용 신규. 여유분 1~2개 권장 (개체 편차 있음)
03전자 저항 10kΩ, 1/4W 4 구매 필요 보유분 4개는 왼발에 사용 중. 신규 필요. BNO055 풀업용 2개도 같이 주문
04전자 NU-40 DK 보드 nRF52840, Qwiic ×2 1 현장 대여 현장 구매 가능 (가격 미확인). 구매해야 들고 올 수 있음
05전자 MPU-6050 6축 IMU Qwiic, I2C 0x68 1 현장 대여 Hard Mode 기본 제공. 종료 후 반납
06전자 Qwiic 케이블 4핀 JST 1mm 2 현장 대여 NU40↔ADS1015, NU40↔MPU6050. 짧을수록 400kHz 안정
07전자 LiPo 배터리 3.7V 300mAh, JST 1 현장 대여 보유 880mAh보다 작음. 데모 시간엔 충분
08전자 30AWG 실리콘 케이블 5색 25m 적량 보유 · 재사용 색상 표준 유지: 검정=GND / 빨강=A0 / 노랑=A1 / 초록=A2 / 파랑=A3
09재료 EVA 깔창 235mm, 오른발 1 구매 필요 왼발용과 좌우 대칭. 다이소·마트에서 당일 구입 가능
10재료 자석 시트 + 자석 자석 ×4 1세트 보유 · 재사용 FSR 위치 가변 고정. 잔량 확인 필요
11재료 열수축 튜브 소경 적량 보유 · 재사용 저항 절연 겸용. 분압 저항을 케이블에 직결 후 감싸면 쇼트 위험 제거
12재료 패브릭 테이프 얇은 타입 1롤 보유 · 재사용 인솔 케이블 고정
13재료 PP 케이스 (기성품) 투명, 100×70×40mm 이상 2~3 구매 필요 다이소. 보드 3장 수납. 투명 = 데모 시 내부 가시성. 실패 대비 복수 구입
14공구 미니 브레드보드 170홀 또는 830홀 1 보유 · 재사용 현장 우회용 백업. 배선 문제 시 즉시 재구성
15공구 정밀 드라이버 (일자) 나사단자용 소형 1 선택 ADS1015 나사단자 조임에 필수. 없으면 현장에서 못 물림
16공구 멀티미터 ZOYI ZT102 1 보유 · 재사용 도통 확인. 현장 지참 권장
17공구 솔더링 인두 + 납 — 1세트 선택 현장 사용 가능 여부 확인 필요. 사전 작업 완료 시 불필요
18공구 USB-C 데이터 케이블 충전 전용 아님 1 보유 · 재사용 가이드에 명시된 흔한 실패 원인. 데이터 통신 가능 여부 사전 확인
오늘(8/17) 안에 주문해야 하는 것
  • ADS1015 Qwiic ADC ×2 — 디바이스마트 / 아이씨뱅큐. 배송 3~4일이면 오늘이 마지노선
  • FSR402 ×4~6 — 오른발 신규
  • 10kΩ 저항 ×6 — 오른발 분압 4개 + BNO055 풀업 2개
오프라인 당일 구입 가능: EVA 깔창, PP 케이스, 정밀 드라이버
운영진 확인 필요 (카톡 오픈채팅)
  • NU-40 DK 현장 구매 가격
  • 보드에 LiPo 충전 회로 내장 여부 — 내장이면 TP4056·MT3608 완전 제거 가능
  • 현장 납땜 가능 여부 / 인두 지참 허용
  • ADS1015 사전 구매 반입 시 반납 대상인지 (본인 구매품이므로 아닐 것으로 예상)

펌웨어 수정 범위 — 3곳
  • FSR 읽기 — analogRead() → ADS1015 라이브러리 호출, 반전 상수 재계산
  • IMU 융합 — BNO055 Euler 직접 읽기 → MPU-6050 raw + Madgwick 필터
  • BLE 초기화 — ESP32 NimBLE → Bluefruit BLEUart
임계값 판정, 오디오 피드백, 세션 품질 계산 등 나머지 로직은 그대로 유지.
