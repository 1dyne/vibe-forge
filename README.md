# 달그락 대장간

아이디어를 채팅으로 다듬고, 회로와 회전 가능한 3D 목업을 승인한 뒤, 대장 및 HW/SW/ME/ID 달그락과 구매·제작·평가를 진행하는 제작 보조 에이전트입니다.

기본 명세는 `달그락-대장간-1차-개발-명세서-v0.5.md`, 최신 사용자 흐름은 `docs/WORKFLOW-v0.6.md`입니다. 환경 설정은 `docs/SETUP-v0.5.md`, 검증 결과와 남은 범위는 `docs/STATUS.md`를 봅니다.

## 실행

```powershell
npm install
npm test
npm run typecheck
npm run build
npm run doctor
npm run dev
```

`.env.local`에 APP_PASSWORD와 SESSION_SECRET을 설정합니다. APP_MODE=mock에서는 유료 모델을 호출하지 않습니다. live는 Sonnet 작업과 Opus 평가를 사용하고, 설정된 API 비용 한도에 따라 요청을 제한합니다.

접속 주소는 `http://localhost:3000`입니다. 개인 작업 공간의 비밀번호로 로그인하며, ‘로그인 유지’를 선택하면 이 기기에서 30일간 세션을 유지합니다(기본 12시간). 왼쪽 아래에서 로그아웃할 수 있습니다. 배포 환경에도 서버 환경변수로 APP_PASSWORD와 SESSION_SECRET을 설정해야 합니다. 현재 데이터 저장은 로컬 파일 기반이므로 배포 시 영구 디스크가 필요합니다.

달그락 대장간 배너와 ‘새로운 아이디어’는 시작 화면으로 이동합니다. 프로젝트 목록과 각 프로젝트 폴더를 접고 펼쳐서 프로젝트별 작업실을 선택합니다. 작업물은 실제 파일명으로 ‘작업대’에 나타나며, 새 작업물이 생성되면 작업대가 열립니다. 파일 미리보기·원문·다운로드를 지원합니다. 부품 목록·작업 목록·팀 기록은 해당 프로젝트의 현재 데이터를 담은 문서로 내려받습니다.

프로젝트 영역·대화/작업대 사이·입력 영역 위 경계를 드래그하면 크기가 바뀝니다. 경계에 키보드 초점을 두고 방향키로도 조절할 수 있습니다. 폴더의 펼침 상태, 작업대의 표시·선택 파일과 구역 크기는 브라우저에 저장하며, ‘구역 크기 초기화’로 되돌릴 수 있습니다. 좁은 창에서는 작업대를 대화 아래에 배치합니다.

## 사용 흐름

1. 아이디어와 참고 이미지를 입력하면 프로젝트가 만들어지고 대장이 추가 질문합니다.
2. 제작 프로필에서 핵심 동작·보유 도구·펌웨어 경험을 확인하고 계획을 시작합니다.
3. 오른쪽 회로를 승인하면 3D 목업이 생성됩니다. 드래그로 돌려본 뒤 방향을 승인합니다.
4. BOM 구매 상태와 다음 할 일의 사람/AI 작업을 확인하고 참여 에이전트를 선택해 대장간에 들어갑니다.
5. 메인방 또는 각 작업실에서 대화하고 작업/Evaluator 모드를 선택합니다. 변경 제안과 결과는 팀 공통 기록에 공유됩니다.
6. 펌웨어·OpenSCAD·작업실 초안을 내려받고 실제 측정·IDE 실행 결과를 제출합니다. 실물 검증이 없는 항목은 unknown으로 남습니다.

프로젝트는 `.data/local-projects.json`에 저장합니다. 현재 3D는 치수 기반 목업이며, 코드 파일은 자동 실행하지 않습니다. 실시간 재고 검색과 운영 DB/독립 백그라운드 worker는 후속 작업입니다.

## 폴더

- `apps/web`: Next.js 화면과 API
- `apps/worker`: 후속 큐 워커 진입점
- `packages/schema`, `domain`, `rules`: 상태 계약과 결정론적 검사
- `packages/agents`: OpenAI·Anthropic·mock 어댑터
- `packages/db`: Postgres 스키마와 migration
- `config`: 모델 역할·비용·판매처 설정
- `tests`: 유료 API 없이 실행되는 회귀 검사
- `asset`: 제공된 캐릭터 원본
