# 달그락 대장간 제출용 시연 영상

- 파일: dalgeurak-demo.mp4
- 길이: 약 2분
- 화면: 1440×1080, H.264 MP4, 24fps
- 음성: 없음 (한국어 설명 자막 포함)
- 시연: 실제 로컬 웹 화면, 실제 Sonnet/Opus 응답
- 편집: 일부 AI 응답 대기 구간 단축, 단계별 자막과 제목 카드 추가
- 범위: 아이디어 입력 → 추가 질문 → 제작 프로필 → 회로 → 사용자 승인 → 회전 가능한 3D → 작업 분담/BOM → 메인 팀 협업 → HW Evaluator → ME 파일 생성·공유 → 펌웨어 파일

촬영한 프로젝트는 로컬 앱의 ‘눈반짝이 책상친구’입니다. 시연 조건을 사용했으며 실물 계측이나 Arduino 컴파일 완료를 뜻하지 않습니다. 판매처 재고 검색은 아직 연결되지 않았습니다.

index.html을 같은 폴더에서 열면 미리보기와 다운로드 버튼을 사용할 수 있습니다. 개발 서버가 실행 중이면 http://localhost:3000/demo/index.html에서도 재생할 수 있습니다. 외부에 공개 배포한 URL은 아닙니다.
