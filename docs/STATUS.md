## 현재 경계와 후속 작업

- 로컬 JSON 개발 저장소를 사용한다. Postgres migration·worker 골격은 있으나 운영 DB/queue 연결과 독립 백그라운드 에이전트는 미완성.
- 메인방은 한 번의 모델 요청으로 선택한 역할의 답변을 조율한다. 개별방은 해당 역할만 응답한다.
- 3D는 제안 치수 기반의 회전 가능한 기구 목업이다. 실제 부품 형상·공차 검증, OpenSCAD 렌더/STL, 실물 조립 검증은 별도다.
- 파일은 자동 실행·컴파일·배포하지 않는다. Arduino IDE에서 사용자가 실행하고 결과를 제출하는 MVP 흐름이다.
- 실시간 판매처·가격·재고 검색은 아직 미연결이며 BOM에서 구매 전 확인을 안내한다.
- 회로 배선 과정 재생 기능은 확장 범위로 남아 있다.
- 기존 승인된 설계는 개인방에서 만든 초안으로 자동 덮어쓰지 않는다. 설계 다시 논의 후 재승인한다.

API 키는 출력하지 않았다. APP_MODE=live이며 2026-09-17 사용자의 명시적 승인으로 앱의 턴당·일일 비용 한도를 `Infinity`로 해제했다. 사용량 장부 기록은 계속하며, 제공자 계정 한도는 별개다. 유한한 금액으로 다시 설정하면 앱의 비용 제한이 복구된다.
