# 도깨비 마을 에셋 목록 (다인이 그림)

`docs/UPGRADE`의 Phase 2(내 대장간·골목)와 Phase 4(손바닥 마을)에 들어갈 그림. 그림이 오기 전에는 같은 자리에 단순한 도형을 넣어 기능부터 돌리고, 그림이 오면 파일만 바꿔 끼운다.

## 공통 규칙

- **형식**: 투명 배경 PNG. 애니메이션은 지금 도깨비 스프라이트와 같은 시트(512×512 프레임, 5열, 프레임당 80ms) + 같은 JSON.
- **선**: 지금 캐릭터처럼 검은 외곽선 `#232323`, 손그림 굵기.
- **시점**: 대장간·골목은 **2D 등축(isometric) 2:1** (가로 2칸 : 세로 1칸 마름모 바닥). 모든 오브젝트를 같은 각도로.
- **크기 기준**: 바닥 타일 한 칸 = 가로 256px. 오브젝트 크기는 몇 칸을 차지하는지로 정함.
- **색**: 캐릭터 청록 `#9ED3CB`, 바탕 `#F6F5F1`. 불 색(빛 보라 `#9B7BFF` · 소리 주황 `#FF8F3F` · 움직임 초록 `#3FBF6E` · 고요 청록 `#4FB3A6`)은 코드에서 입힐 수 있게 **불·기운 부분은 흰색/회색 단독 레이어**로 따로 주면 좋음.
- **파일 이름**: 영어 소문자-하이픈. 예: `room-cat.png`, `piece-light.png`.
