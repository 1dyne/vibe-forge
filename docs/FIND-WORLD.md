# 도깨비 마을 (3D) 설계 규칙

`/find/world`의 걷는 마을과 `/f/:id`의 대장간 안이 **무엇을 보고 어떻게 바뀌는지** 정리한 문서다.
다인이 정한 것(마을 5개, 마을별 분위기·재료·랜드마크, 집 3단계)은 그대로 두었다. 다인이 정하지 않은 부분(골목 구성, 기척 표시, 대장간 안)은 Claude가 짰다. 아래 표에서 이 둘을 구분했다.

코드 위치
- 마을·골목·성장 단계: `apps/web/lib/find/village.ts`
- 기척(마지막으로 본 시각): `apps/web/lib/find/village-store.ts`의 `touchForge`·`activeForgeIds`, API `/api/find/presence`
- 바깥 마을: `apps/web/app/find/world/world-build.ts`(장면) · `world-view.tsx`(조작)
- 대장간 안: `apps/web/app/find/forge-room.tsx`

## 1. 마을 (골목은 이름 없이)

마을은 큰 제작 분야다. 사람들에게 보이는 주소는 **마을 이름뿐**이다. 표지판도 마을 문에만 있다.
안에서는 도깨비불의 장작과 가장 맞는 관심사끼리 이웃해서 모인다. 이게 이름 없는 골목이다(`ALLEY_THEMES`). 관심사가 바뀌는 자리에는 작은 화단이 경계를 만든다.

| 마을 | 분야 | 안에서 모이는 관심사(내부 id) |
|---|---|---|
| 꼬물마을 | 돌봄·반려동물·식물·가족 | cat · dog · plant · family |
| 뚝딱마을 | 생활 편의·살림·자동화 | kitchen · switch |
| 째깍마을 | 시간·습관·집중·업무 | desk · sleep · water |
| 와글마을 | 놀이·장난감·상호작용 | toy · kid |
| 깜빡마을 | 관찰·감지·상태 확인 | door · air · noise |

### 마을 문 (입장 조건)
- `/find/village`는 내 도깨비불을 찾고, 그 도깨비불로 **대장간 오픈 알림 이메일**을 남긴 사람에게 열린다(`villageOpenFor`).
  - 이메일을 남기면 그 자리에서 "도깨비 마을 문이 열렸어 → 마을로 들어가기"가 뜬다.
  - 대장간이 없으면 "내 도깨비불 찾기", 대장간만 있으면 마을 문 앞에서 이메일 신청 화면이 뜬다.
- 공유된 대장간 링크(`/f/:id`)는 누구나 볼 수 있다. 바이럴 입구다.

## 2. 바깥 마을

- 가운데 광장에서 길 다섯 갈래가 다섯 마을로 이어진다.
  - 광장에는 본관 공사장, 소식판, 가로등, 벤치가 있다.
  - 마을마다 마을 문, 고리 모양 길, 랜드마크, 골목 표지판이 있다.
- 미술 규칙은 하나로 맞췄다: 로우폴리, 납작한 색, 둥근 비율.
- 마을마다 바뀌는 것: 색, 재료, 집 양식, 랜드마크, 자연물.

| 마을 | 집 양식 | 랜드마크 | 자연물 |
|---|---|---|---|
| 꼬물 | 크림 회벽 + 세이지 박공지붕, 앞마당 울타리 | 큰 나무 아래 둥근 쉼터 | 사과나무, 클로버, 꽃밭 |
| 뚝딱 | 붉은 벽돌 + 함석지붕, 차양, 도는 톱니 | 톱니바퀴가 도는 풍차 | 나무통, 상자, 자갈길 |
| 째깍 | 좁고 높은 석조 + 남색 뾰족지붕, 작은 시계 | 실제 시각을 가리키는 시계탑 | 은행나무, 억새, 돌계단 |
| 와글 | 둥근 버터색 집 + 코랄 지붕, 바람개비 | 걸어다니는 태엽 장난감 | 민들레, 둥근 덤불, 튀는 공 |
| 깜빡 | 밝은 석재 + 유리 돔 + 구리 테, 깜빡이는 안테나 | 풍향계가 도는 관측탑 | 연못, 갈대, 이끼, 신호등 |

### 대장간 성장 단계 (마을 5개 × 3단계 = 외형 15가지)
단계는 그 집 도깨비불들의 구상 수준 중 가장 높은 것으로 정한다(`houseStage`).
- **불씨**: 장작 갈래가 1개 이하이거나 장작이 2개 이하.
- **타오름**: 갈래가 2~3개.
- **활활**: 형태·반응·감지·누구 네 갈래를 다 채움.

단계가 오르면 집이 커지고 장식이 붙는다.
- 불씨: 양철 연통.
- 타오름: 굴뚝, 꽃상자, 상자, 가로등.
- 활활: 별채, 탑, 망원경, 풍선.

### 마을의 기척 (접속 중인 사람은 드러내지 않는다)
- 누가 접속해 있는지는 이름으로도 아바타로도 보여주지 않는다. 마을엔 빈집만 있고, 집이 살아 있는 것처럼 연출한다.
- 실시간 서버는 쓰지 않는다. 대장간마다 **마지막으로 본 시각**(`last_seen`) 하나만 저장한다.
  - 주인이 걷는 마을·지도·자기 대장간을 볼 때 이 시각을 남긴다.
  - 걷는 마을 화면은 1분 반마다 `/api/find/presence`를 부른다.
  - 쓰기는 2분에 한 번으로 묶었다.

| 신호 | 집에 보이는 것 |
|---|---|
| 주인이 지금 마을에 있음 (10분 안) | 창문이 화롯불처럼 일렁이고, 굴뚝 연기가 굵고 빠르다. 문 앞이 밝고, 떠 있는 도깨비불이 빨리 움직인다 |
| 최근 24시간 안에 주인이 왔거나 7일 안에 손님이 다녀감 | 창문이 은은하게 켜져 있다 |
| 도깨비불(아이디어)이 2개 이상 쌓임 | 굴뚝에서 가는 연기가 오른다(최대 3줄기) |
| 이웃에게 받은 장작 | 굴뚝 불꽃이 커진다 |
| '나도 갖고 싶어' 5개 이상 | 지붕에 깃발이 선다 |

### 마을 연출 (가짜 사람 없이, 원래 이 마을에 사는 것들)
전부 화면 안에서만 돌아서 서버 비용이 없다.
- **떠돌이 도깨비불 행렬**: 마을마다 4개씩 줄지어 광장과 마을 고리 길을 오간다. 달그락이 다가가면 흩어졌다가 다시 모인다.
- **혼자 떠도는 불**: 언덕 위를 느리게 떠돈다. 밤엔 더 많아진다.
- **발자국**: 최근에 실제로 손님이 다녀간 집 문 앞에서만, 몇 걸음 찍혔다가 사라진다.
- **마을마다 사는 것**: 꼬물엔 나비, 뚝딱엔 고리 길을 굴러다니는 톱니, 와글엔 혼자 걷는 태엽 장난감, 깜빡엔 반딧불이(밤엔 많아짐).
- **하루 시간대**: 보는 기기의 시각을 따른다.
  - 낮: 맑음.
  - 새벽(5~8시): 안개.
  - 저녁(17~19시): 노을.
  - 밤(19~5시): 남색 하늘, 별, 모든 창문이 켜지고 반딧불이·떠도는 불이 늘어난다.
- **째깍마을 시계탑**: 실제 시각을 가리키고, 정시가 되면 30초 동안 종이 크게 흔들린다.

## 3. 대장간 안 (Claude가 짰다)

대장간 안은 동물의 숲의 '내 집'에 해당한다. 새 아이디어를 넣으면 새 집이 생기지 않고 **이 방이 변한다**. 벽·바닥 재료는 집이 있는 마을을 따른다.

| 마을 | 벽 | 바닥 |
|---|---|---|
| 꼬물 | 크림 회벽 + 나무 기둥 | 밝은 마루 |
| 뚝딱 | 붉은 벽돌 | 짙은 마루 |
| 째깍 | 회색 석재 | 짙은 나무 |
| 와글 | 버터색 줄무늬 | 코랄 체크 |
| 깜빡 | 밝은 석재 + 둥근 창 | 청록 타일 |

| 쌓이는 것 | 방에서 바뀌는 것 |
|---|---|
| 성장 단계 | **방 크기**: 불씨는 작은 방, 창 하나. 타오름은 창 둘, 러그, 매단 등. 활활은 넓은 방, 다락, 사다리, 풀무 |
| 도깨비불 개수 | **선반**: 하나에 빛나는 유리병 하나(병 색 = 불 색). 병이 늘면 선반 칸이 는다(활활은 16병까지, 넘으면 +N) |
| 성장 단계 | **작업대**: 메모 쪽지 → 펼친 설계도와 자 → 부품 상자 + 불 색으로 깜빡이는 시제품 |
| 도깨비불 개수 | **설계도 판**: 핀으로 꽂은 쪽지(최대 6장). 타오름부터 큰 청사진이 붙는다 |
| 채운 장작 갈래 | **공구 걸이**: 감지 = 돋보기, 반응 = 종, 형태 = 자, 누구 = 액자 |
| 화력 + 받은 장작 | **화로** 불 크기. 불 색 = 가장 최근 도깨비불. 옆 **장작더미** = 받은 장작 수 |
| '나도 갖고 싶어' | **진열대**: 1개 이상이면 리본, 5개 이상이면 트로피 |
| 놀러 온 도깨비의 말 | **우체통**에 꽂힌 편지(최대 3통) |
| 이웃 수 | 벽 **액자**(최대 4개) |

- 달그락이 화로 옆을 지킨다.
- 물건을 누르면 기존 시트가 열린다(화로 = 카드, 설계도, 선반, 작업대 = 발명품, 우체통). 장작더미·공구 걸이·진열대를 누르면 한 줄 설명이 뜬다.
- 옆으로 끌면 방을 조금 돌려볼 수 있다.
- WebGL이 안 되는 기기는 예전 2D 방 그림을 보여준다.

## 4. 내 달그락과 꾸미기

- **내 달그락 색**: 마을을 걷는 달그락과 대장간 안 달그락은 온보딩에서 받은 색 그대로다. 가장 최근 도깨비불의 반응 갈래로 정하고, 온보딩 화면과 같은 hue-rotate 각도(`REACT_HUE`)를 3D 셰이더에 그대로 적용한다(`app/find/three-hue.ts`).
- **내 집 앞으로**: 결과 화면의 "마을로 나가서 내 집 앞에 서보기", 대장간의 "마을로 나가기", 마을의 "내 집 앞으로"를 누르면 `/find/world?house=<id|me>`로 가서 내 집 문 앞에서 시작한다. 비공개·링크 전용 집도 주인에게는 보인다.
- **꾸미기** (대장간 → "대장간 꾸미기", 규칙은 `lib/find/decor.ts`):

| 항목 | 선택지 | 열리는 조건 |
|---|---|---|
| 지붕 색 | 마을 기본 + 10색 | 처음부터 |
| 간판 모양 | 나무판 · 둥근 간판 · 깃발 · 등불 | 처음부터 |
| 집 앞 꾸미기 (최대 3개) | 화분 · 우체통 · 울타리 | 처음부터 |
| | 벤치 | 이웃 3명 |
| | 가로등 | 받은 장작 10개 |
| | 꽃 아치 | '나도 갖고 싶어' 5개 |
| | 풍경 | 놀러 온 도깨비가 남긴 말 5개 |
| 마을에 내 기척 보이기 | 켬(기본) / 끔 | 끄면 창문 일렁임·굵은 연기·'최근에 왔음' 불빛이 사라진다 |

- 서버가 저장 전에 다시 거른다. 모르는 색, 안 열린 꾸미기, 4개 이상은 빠진다.
