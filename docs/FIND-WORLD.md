# 도깨비 마을 (3D) 설계 규칙

`/find/world`의 걷는 마을과 `/f/:id`의 대장간 안이 **무엇을 보고 어떻게 바뀌는지** 정리한 문서다.
다인이 정한 것(마을 5개, 마을별 분위기·재료·랜드마크, 집 3단계)은 그대로 두었다. 다인이 정하지 않은 부분(골목 구성, 기척 표시, 대장간 안)은 Claude가 짰다. 아래 표에서 이 둘을 구분했다.

코드 위치
- 마을·골목·성장 단계: `apps/web/lib/find/village.ts`
- 기척(마지막으로 본 시각): `apps/web/lib/find/village-store.ts`의 `touchForge`·`activeForgeIds`, API `/api/find/presence`
- 바깥 마을: `apps/web/app/find/world/world-build.ts`(장면) · `world-view.tsx`(조작)
- 대장간 안: `apps/web/app/find/forge-room.tsx`

## 1. 마을 (골목은 이름 없이)

마을은 큰 제작 분야다. 사람들에게 보이는 주소는 **마을 이름뿐**이다. 표지판도 마을 문에만 있다.
안에서는 도깨비불의 장작과 가장 맞는 관심사끼리 이웃해서 모인다. 이게 이름 없는 골목이다(`ALLEY_THEMES`). 관심사가 바뀌는 자리에는 작은 화단이 경계를 만든다.

| 마을 | 분야 | 안에서 모이는 관심사(내부 id) |
|---|---|---|
| 꼬물마을 | 돌봄·반려동물·식물·가족 | cat · dog · plant · family |
| 뚝딱마을 | 생활 편의·살림·자동화 | kitchen · switch |
| 째깍마을 | 시간·습관·집중·업무 | desk · sleep · water |
| 와글마을 | 놀이·장난감·상호작용 | toy · kid |
| 깜빡마을 | 관찰·감지·상태 확인 | door · air · noise |

### 마을 문 (입장 조건)
- `/find/village`는 내 도깨비불을 찾고, 그 도깨비불로 **대장간 오픈 알림 이메일**을 남긴 사람에게 열린다(`villageOpenFor`).
  - 이메일을 남기면 그 자리에서 "도깨비 마을 문이 열렸어 → 마을로 들어가기"가 뜬다.
  - 대장간이 없으면 "내 도깨비불 찾기", 대장간만 있으면 마을 문 앞에서 이메일 신청 화면이 뜬다.
- 공유된 대장간 링크(`/f/:id`)는 누구나 볼 수 있다. 바이럴 입구다.

## 2. 바깥 마을 (고증 기준: 아트 디렉션 무드보드)

- **땅:** 하회마을처럼 물이 감싸 도는 땅이다. 한가운데 호수 섬에 본관 대장간이 있고, 섶다리 넷과 돌다리 하나로 다섯 마을과 이어진다.
- **시간:** 늘 해 질 녘이고(각색), 실제 밤(19~5시)엔 밤이 된다. 하늘·안개·빛 색은 시간대마다 한 묶음(`PALETTE`)이다. 초승달이 뜨고, 밤엔 별이 뜬다.
- **빛:** 두 종류로 나눈다.
  - 사람의 불빛(따뜻한 주황): 창호지 창, 초롱, 화톳불
  - 도깨비불(서늘한 청록·연보라)
  - 가로등은 없다. 청사초롱은 혼례용이라 쓰지 않는다.
- **마을 입구:** 장승 한 쌍, 솟대, 나무 목패(마을 이름), 화톳불이 있다. 고갯마루엔 서낭당(돌무더기 + 오색천을 맨 신목)이 있다.
- **미술 규칙:**
  - 로우폴리, 납작한 색.
  - 지붕·장승·랜드마크에만 먹선 외곽선을 넣는다(민화 느낌).
  - 민가엔 단청이 없다. 붉은색은 도깨비 쪽에 쓰지 않는다.
- **물:** 하늘빛이 비치는 가짜 반사와 잔물결, 물안개, 물가 버드나무와 갈대.

| 마을 | 집 (기본 지붕) | 랜드마크 | 자연물·소품 | 오래 쓴 물건 도깨비 |
|---|---|---|---|---|
| 꼬물 | 초가, 싸리울, 텃밭 | 당산나무(큰 느티나무)와 평상 | 감나무, 메밀꽃 | 빗자루(마당 쓸기), 키 |
| 뚝딱 | 앞이 트인 대장간(화덕·풀무·모루), 잿빛 기와 | 냇물로 도는 물레방아 | 소나무, 장작더미, 옹기, 화톳불 | 부지깽이 |
| 째깍 | 먹기와집(서당), 활활 단계엔 누마루 | 해시계(앙부일구 모양, 실제 시각 그림자)와 북 정자(정시에 북) | 은행나무, 억새 | 절굿공이 |
| 와글 | 너와집, 널·방패연 | 씨름판(모래판)과 큰 그네 | 덤불, 느티나무 | 짚신(씨름하는 둘 + 뛰어다니는 하나) |
| 깜빡 | 갈대 이엉 집, 활활 단계엔 물가 망루 | 봉수대(연조 다섯 중 하나만 불, 평상시) | 갈대밭·늪, 대나무, 반딧불이, 도깨비불 무리 | 도깨비불 |

- 확인이 더 필요한 고증: 장독대, 해시계의 위치, 봉수대의 평상시 신호(무드보드의 '확인 필요' 표시).

### 대장간 성장 단계 (마을 5개 × 3단계 = 외형 15가지)
단계는 그 집 도깨비불들의 구상 수준 중 가장 높은 것으로 정한다(`houseStage`).
- **불씨**: 장작 갈래가 1개 이하이거나 장작이 2개 이하.
- **타오름**: 갈래가 2~3개.
- **활활**: 형태·반응·감지·누구 네 갈래를 다 채움.

단계가 오르면 집이 커지고 장식이 붙는다.
- 불씨: 작은 한 칸 집, 낮은 굴뚝.
- 타오름: 툇마루와 디딤돌(대장간 마을은 장작더미), 마을별 소품(와글은 널).
- 활활: ㄱ자로 한 칸 덧붙인 집(대장간 마을은 곳간), 마을별 소품(째깍은 누마루, 와글은 방패연, 깜빡은 망루).

### 마을의 기척 (접속 중인 사람은 드러내지 않는다)
- 누가 접속해 있는지는 이름으로도 아바타로도 보여주지 않는다. 마을엔 빈집만 있고, 집이 살아 있는 것처럼 연출한다.
- 실시간 서버는 쓰지 않는다. 대장간마다 **마지막으로 본 시각**(`last_seen`) 하나만 저장한다.
  - 주인이 걷는 마을·지도·자기 대장간을 볼 때 이 시각을 남긴다.
  - 걷는 마을 화면은 1분 반마다 `/api/find/presence`를 부른다.
  - 쓰기는 2분에 한 번으로 묶었다.

| 신호 | 집에 보이는 것 |
|---|---|
| 주인이 지금 마을에 있음 (10분 안) | 창호지 창이 화롯불처럼 일렁이고(창 불빛 = 주인 도깨비불 색이 섞인 주황), 굴뚝 연기가 굵고 빠르다 |
| 최근 24시간 안에 주인이 왔거나 7일 안에 손님이 다녀감 | 창문이 은은하게 켜져 있다 |
| 도깨비불(아이디어)이 2개 이상 쌓임 | 굴뚝에서 가는 연기가 오른다(최대 3줄기) |
| 이웃에게 받은 장작 | 굴뚝 불꽃이 커진다 |
| '나도 갖고 싶어' 5개 이상 | 집 옆에 장대 깃발이 선다 |

### 마을 연출 (가짜 사람 없이, 원래 이 마을에 사는 것들)
전부 화면 안에서만 돌아서 서버 비용이 없다.
- **떠돌이 도깨비불 행렬**: 마을마다 4개씩 줄지어 광장과 마을 고리 길을 오간다. 달그락이 다가가면 흩어졌다가 다시 모인다.
- **혼자 떠도는 불**: 언덕 위를 느리게 떠돈다. 밤엔 더 많아진다.
- **발자국**: 최근에 실제로 손님이 다녀간 집 문 앞에서만, 몇 걸음 찍혔다가 사라진다.
- **마을마다 사는 것**: 꼬물엔 나비, 뚝딱엔 고리 길을 굴러다니는 톱니, 와글엔 혼자 걷는 태엽 장난감, 깜빡엔 반딧불이(밤엔 많아짐).
- **하루 시간대**: 보는 기기의 시각을 따른다.
  - 낮: 맑음.
  - 새벽(5~8시): 안개.
  - 저녁(17~19시): 노을.
  - 밤(19~5시): 남색 하늘, 별, 모든 창문이 켜지고 반딧불이·떠도는 불이 늘어난다.
- **째깍마을 시계탑**: 실제 시각을 가리키고, 정시가 되면 30초 동안 종이 크게 흔들린다.

## 3. 대장간 안 (Claude가 짰다)

대장간 안은 동물의 숲의 '내 집'에 해당한다. 새 아이디어를 넣으면 새 집이 생기지 않고 **이 방이 변한다**.

벽은 모든 마을이 흙벽에 나무 기둥과 인방이고, 마을마다 흙 색만 조금씩 다르다. 창은 한지 바른 살창이다. 바닥은 마루이고, 대장간 마을(뚝딱)만 흙바닥이다. 유리·벽돌·타일·청사진 같은 근대 재료는 쓰지 않는다.

| 쌓이는 것 | 방에서 바뀌는 것 |
|---|---|
| 성장 단계 | **방 크기**: 불씨는 작은 방, 창 하나. 타오름은 창 둘, 돗자리, 등잔. 활활은 넓은 방, 다락, 사다리, 큰 풀무 |
| 도깨비불 개수 | **선반**: 하나에 한지 초롱 하나(초롱 불빛 = 불 색). 초롱이 늘면 선반 칸이 는다(활활은 16개까지, 넘으면 +N) |
| 성장 단계 | **작업대**: 메모 쪽지 → 펼친 한지 설계도와 붓 → 부품 함 + 불 색으로 깜빡이는 시제품 |
| 도깨비불 개수 | **설계도 판**: 붙여 둔 한지 쪽지(최대 6장). 타오름부터 먹으로 그린 큰 설계도가 붙는다 |
| 채운 장작 갈래 | **연장 걸이**: 감지 = 돋보기, 반응 = 종, 형태 = 자, 누구 = 패 |
| 화력 + 받은 장작 | 흙 **화덕** 불 크기(풀무가 숨 쉬듯 움직임). 불 색 = 가장 최근 도깨비불. 옆 **장작더미** = 받은 장작 수 |
| '나도 갖고 싶어' | **소반**: 1개 이상이면 메밀묵 한 그릇(도깨비가 좋아하는 제물), 5개 이상이면 금빛 초롱 |
| 놀러 온 도깨비의 말 | 나무 **편지함**에 꽂힌 편지(최대 3통) |
| 이웃 수 | 벽 **족자**(최대 4개) |

- 달그락이 화로 옆을 지킨다.
- 물건을 누르면 기존 시트가 열린다(화덕 = 카드, 설계도, 선반, 작업대 = 발명품, 편지함). 장작더미·연장 걸이·소반을 누르면 한 줄 설명이 뜬다.
- 옆으로 끌면 방을 조금 돌려볼 수 있다.
- WebGL이 안 되는 기기는 예전 2D 방 그림을 보여준다.

## 4. 내 달그락과 꾸미기

- **내 달그락 색**: 마을을 걷는 달그락과 대장간 안 달그락은 온보딩에서 받은 색 그대로다. 가장 최근 도깨비불의 반응 갈래로 정하고, 온보딩 화면과 같은 hue-rotate 각도(`REACT_HUE`)를 3D 셰이더에 그대로 적용한다(`app/find/three-hue.ts`).
- **내 집 앞으로**: 결과 화면의 "마을로 나가서 내 집 앞에 서보기", 대장간의 "마을로 나가기", 마을의 "내 집 앞으로"를 누르면 `/find/world?house=<id|me>`로 가서 내 집 문 앞에서 시작한다. 비공개·링크 전용 집도 주인에게는 보인다.
- **꾸미기** (대장간 → "대장간 꾸미기", 규칙은 `lib/find/decor.ts`):

| 항목 | 선택지 | 열리는 조건 |
|---|---|---|
| 지붕 | 마을 기본 · 초가 · 갈대 이엉 · 먹기와 · 잿빛 기와 · 너와 | 처음부터 |
| 문패 | 나무 문패 · 둥근 문패 · 깃대(천 색 = 내 도깨비불 색) · 초롱 | 처음부터 |
| 집 앞 꾸미기 (최대 3개) | 장독 · 싸리울 · 메밀꽃밭 | 처음부터 |
| | 평상 | 이웃 3명 |
| | 초롱 걸이 | 받은 장작 10개 |
| | 작은 솟대 | '나도 갖고 싶어' 5개 |
| | 풍경 | 놀러 온 도깨비가 남긴 말 5개 |
| 마을에 내 기척 보이기 | 켬(기본) / 끔 | 끄면 창문 일렁임·굵은 연기·'최근에 왔음' 불빛이 사라진다 |

- 내 색은 지붕이 아니라 **창호지 불빛 색**으로 드러난다(내 도깨비불 색을 섞은 주황).
- 예전에 저장된 서양식 꾸미기는 읽을 때 새 이름으로 바꾼다(`readDecor`).
  - 화분 → 장독, 우체통 → 메밀꽃밭, 벤치 → 평상, 가로등 → 초롱 걸이, 꽃 아치 → 작은 솟대
  - 지붕 색은 버리고 마을 기본 재료로 돌린다.

- 서버가 저장 전에 다시 거른다. 모르는 색, 안 열린 꾸미기, 4개 이상은 빠진다.

## 5. 소리 (브라우저에서 합성, 녹음 파일 없음)
기본은 꺼짐이다. 화면 위 "소리"를 누르면 켜진다(`world-sound.ts`).
- 물결: 호수에 가까울수록 커진다.
- 갈대 바람: 늘 깔린다.
- 장작 타는 소리: 화톳불, 대장간, 본관 화덕 가까이에서 난다.
- 처마 풍경: 가끔 울린다.
- 풀벌레: 밤에만.
- 북: 정시에 세 번.
- 방울 소리: 도깨비불에 가까이 가면 난다.

## 6. 소원 등불

"누구를 위해" 한 줄과 기원 한 줄을 적어 거는 한지 초롱이다. 코드는 `lib/find/lantern.ts`, API는 `/api/find/lantern`.

| 규칙 | 내용 |
|---|---|
| 거는 곳 | 내 대장간 아래쪽 "등불" 버튼. 내 도깨비불 하나를 골라서 건다 |
| 개수 | 내 대장간의 도깨비불 수만큼(최소 1개). 도깨비불을 새로 찾을 때마다 하나 더 |
| 글 | 누구를 위해 12자, 기원 30자. 욕설·주소·전화번호 같은 숫자열은 거른다. 처음 쓴 아이디어 문장은 어디에도 나오지 않는다 |
| 공개 범위 | 전체 공개 / 대상 이름 가리기 / 나만 보기. 구상안(도깨비불 카드) 함께 공개는 선택 |
| 같은 소원 | 도깨비불의 누구·감지·반응 뿌리 장작이 같으면 한 줄에 꿰인다. 마을 호수를 가로지르는 **소원 줄**에 매달린다(하회 줄불처럼, 한 줄에 최대 9개, 줄은 최대 10개) |
| 솜씨 도깨비 | 남의 등불에 "만들어볼게"를 누르면 등에 망치 표시가 생기고 등이 금빛으로 바뀐다. 완성 인증(사진)은 받지 않는다. 관리 부담을 없애려고 |
| 이뤄졌어 | 주인이 누르면 등불이 호수에 띄운 유등이 되어 천천히 돈다(진주 남강유등처럼) |
| 같이 고민하기 | **연결까지만** 한다. 소원 줄 안에서 구상안을 공개한 도깨비들의 대장간으로 가는 길만 열어준다. 댓글·초대·메모는 넣지 않는다 |
| 대장간 안 | 뒷벽 도리에 내 등불이 매달린다(이뤄진 것은 금빛) |
