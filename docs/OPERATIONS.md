# 달그락 대장간 · 가입과 운영 설계

> 기준: 2026-11-04, 브랜치 `claude/compassionate-babbage-hj0l0a`. 보안 세부는 [`SECURITY.md`](SECURITY.md).

## 1. 계정 모델

| 종류 | 들어오는 법 | 기록 잠금 |
|---|---|---|
| 이메일 계정 (기본) | `/join`에서 별명·이메일·비밀번호 → 인증 메일 → `/login` | 비밀번호·복구 코드로만 열림 (운영자도 못 봄) |
| 구글 계정 (선택) | `/join`에서 "구글로 가입하기" → 안내문 동의 → 구글 | 서버 보관 (`VAULT_MASTER_KEY`). 비밀번호 설정 시 이메일 계정과 같은 잠금 |
| 예전 링크 계정 | `/u#<토큰>` 링크 | 링크로 열림. 내 계정에서 이메일·비밀번호로 바꾸기 권장 |
| 운영자 | `/login` 아래 "운영자 로그인" + `APP_PASSWORD` | 참여자 기록 못 봄 |

가입·로그인·비밀번호 찾기·탈퇴 모두 참여자가 혼자 한다. 운영자가 할 일은 아래 설정뿐이다.

## 2. 설정 (Railway → web → Variables)

| 변수 | 값 | 없으면 |
|---|---|---|
| `SIGNUP_MODE` | `open`(누구나) / `invite`(초대 코드 필요) / `closed` | 기본 `closed`: 가입 화면이 닫힘 |
| `RESEND_API_KEY`, `MAIL_FROM` | Resend에서 도메인 인증 후 키, 보내는 주소(예: `달그락 대장간 <no-reply@도메인>`) | 이메일 가입이 "메일 발송이 아직 준비되지 않았어요"로 실패 |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Google Cloud OAuth 클라이언트(웹). 승인된 리디렉션 URI: `<APP_BASE_URL>/api/auth/google/callback` | 구글 버튼이 안 보임 |
| `VAULT_MASTER_KEY` | 32자 이상 무작위. **따로 백업** | 구글 가입이 실패 |

초대 코드는 `SIGNUP_MODE=invite`일 때 `/admin` → 가입 코드에서 만든다(이메일·구글 가입 모두 코드 필요).

## 3. 참여자 셀프서비스 (대시보드 → 👤 내 계정)

| 기능 | 동작 |
|---|---|
| 로그인과 잠금 | 내 로그인 방식과 기록 잠금 수준 표시. 구글·링크 계정은 비밀번호 설정으로 잠금 강화 |
| 비밀번호·복구 코드 | 바꾸기(다른 기기 로그아웃), 복구 코드 새로 만들기 |
| 연결된 앱 | 허용한 앱(claude.ai, Claude Code…) 목록과 연결 끊기 |
| (링크 계정) 새 링크 만들기 | 기록을 새 열쇠로 재암호화하고 예전 링크와 연결된 앱을 즉시 막음 |
| 프로젝트 삭제 | 사이드바 프로젝트 옆 🗑 → 복구 불가 안내 → 이름 다시 입력 → 영구 삭제. 20개 한도에서 자리가 생김. Claude(커넥터)로는 삭제할 수 없음 |
| 내 기록 내려받기 | 모든 프로젝트·제작 프로필 JSON |
| 탈퇴 | ‘탈퇴’ 입력 → 계정·프로젝트·프로필 즉시 삭제 |

## 4. 운영자 업무

| 업무 | 어디서 | 비고 |
|---|---|---|
| 참여자 직접 초대 | `/admin` 링크 만들기 | 주소는 한 번만 보임 |
| 가입 코드 발급·중지 | `/admin` 가입 코드 | 코드는 해시로만 저장 |
| 웹 AI 허용 | `/admin` 체크 | 운영자 API 비용 발생 |
| 링크 중지 | `/admin` | 즉시 막힘, 기록은 남음(아무도 못 엶) |
| 기록 삭제 | `/admin` | 계정+기록 영구 삭제. 링크 잃은 참여자의 삭제 요청 처리용 |
| 감사 기록 확인 | 볼륨 `.data/audit.jsonl` | 가입·초대·중지·삭제·재발급·내보내기·운영자 로그인. 내용은 안 남김 |

운영자가 **할 수 없는 것**(의도): 참여자 기록 열람, 참여자 링크 다시 보기, 잃어버린 링크 복구.

## 5. 배포와 데이터

- 배포 대상: Railway 프로젝트 `dalgeurak-forge` → 서비스 `web` → 볼륨 `forge-data`(`/app/.data`, 5GB, 1대).
- 저장: JSON 파일 3개(`users.json`, `local-projects.json`, `audit.jsonl`). 쓰기는 프로세스 안 큐로 직렬화 → **복제본(replica)을 2대 이상 두면 안 됨.**
- 규모 한계: 매 쓰기가 파일 전체를 다시 씀. 수백 명·수천 프로젝트를 넘으면 Postgres(이미 `packages/db`에 스키마 초안)로 옮긴다. 옮길 때도 참여자 레코드는 `sealed` 열 그대로 옮기면 된다.
- 첫 배포 시 자동 이전: 예전 링크로 만든 평문 기록을 암호화하고 복구용 토큰 사본을 지운다. **이 버전을 배포한 뒤 예전 버전으로 롤백하면 예전 코드는 암호화된 기록을 못 읽는다.** 롤백이 필요하면 이 버전에서 고친다.
- 기존 참여자 영향: 예전 대시보드 링크 `/u/<토큰>`와 예전 커넥터 주소 `/api/mcp/<토큰>`도 계속 동작. 새로 연결할 때는 공개 주소 `/api/mcp` + 허용을 쓰도록 안내.

## 6. 아직 없는 것 (우선순위)

1. **공개 가입 전**: Resend 도메인 인증, 구글 OAuth 동의 화면 게시(테스트 → 프로덕션), 법률 검토.
2. **법률 검토** — `/terms`, `/privacy`는 코드 동작을 적은 초안. 공개 가입 전에 개인정보 보호법(국외 이전 고지 28조의8, 14세 미만, 보유 기간) 검토.
3. **감사 로그 보관 기간** — 처리방침에 1년이라 적었지만 자동 삭제는 아직 없음. 분기마다 오래된 줄 정리하거나 자동화.
4. **공지 채널** — 서비스 변경·종료 30일 전 고지(약관 5항)를 위한 대시보드 배너.
5. **운영자 2단계 인증**, 운영자 여러 명 분리.
6. **모니터링** — `/api/health` 외부 감시, 디스크 사용량 알림.
7. **비활성 계정 정리** — 예: 12개월 미접속 계정 안내 후 삭제 (처리방침에 넣을지 결정).
